# Assets and usage

This local review build contains original project code, SVG flower shapes and CSS styling. All sound is synthesized by the included oscillator/envelope code. No third-party audio recordings, images, icons, font files, JavaScript libraries or downloaded art are included.

System serif font names are CSS fallbacks only. The fonts themselves are provided by the user's operating system and are not redistributed. Standard Unicode characters are text, not packaged artwork.

No third-party asset attribution or bundled third-party license is required for these product files. Python, Node.js, Playwright, Chromium and Xvfb are development/test tools and are not included in the deliverable.
